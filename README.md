#Brother's Day Website 🎁

A creative Brother's Day themed website built using HTML, CSS, and JavaScript.

About the Project

This project is a personalised, interactive Brother's Day webpage created as a frontend development practice project.

It features a creative presentation of memories, messages, and storytelling through a themed website design.

Technologies Used

- HTML5
- CSS3
- JavaScript

Features

- Themed webpage design
- Interactive elements using JavaScript
- Creative storytelling and content sections
- Images and visual elements

What I Learned

- Structuring webpages with HTML
- Styling and designing layouts using CSS
- Adding interactivity using JavaScript
- Organising website content
- Combining HTML, CSS, and JavaScript in one project
